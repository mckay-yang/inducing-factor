# 城乡居民区距离因子说明

## 数据来源

城乡居民区数据使用全球城乡居民区分布栅格数据。该数据集由中科院地理所刘志涛团队于 2024 年 5 月发布在 Zenodo，基于全球人类居住区数据集（GHS-B），融合夜间灯光、遥感数据、开源地理数据以及土地利用等辅助验证数据生成。

## 数据属性

- 时间范围：2000、2005、2010、2015、2020。
- 空间分辨率：100 m。
- 数据格式：GeoTIFF。
- 原始坐标系：Mollweide。
- 栅格类别值：
  - `1`：城市居民区，或城市居民点。
  - `2`：农村居民区，或农村居民点。

## 处理方式

工作流将城市居民区和农村居民区作为两个独立因子处理，而不是合并为一个 resident 值。

每个年份生成两类距离栅格：

- `urban_settlement_dist_YYYY.tif`：到最近城市居民区像元的距离。
- `rural_settlement_dist_YYYY.tif`：到最近农村居民区像元的距离。

处理流程：

1. 生成原始 AOI 的 20 km buffer。
2. 将居民区栅格按 `AOI + 20 km buffer` 裁剪并重投影/对齐到 CLASS 像元。
3. 分别提取值 `1` 和值 `2`，生成城市/农村二值 mask。
4. 对二值 mask 计算 proximity 距离。
5. 输出裁回 CLASS 网格，只保留原始 AOI 内像元；AOI 外为 `NaN`。

距离值单位为近似米。该方法使用栅格距离变换，速度优先，允许约一个像元量级的空间误差。

## 特征列

训练和预测特征中新增两列：

- `dist_to_urban_settlement`
- `dist_to_rural_settlement`

预测 2025 时，居民区距离按历史年份 fallback：优先使用 2020，若缺失则继续向前查找。
